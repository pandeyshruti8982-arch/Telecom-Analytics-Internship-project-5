TellCo Customer Analytics — Single Page Dashboard
This is the corrected single-page Streamlit dashboard for Project 5.

What is included
One continuous dashboard page
Executive KPI cards
Task 1: User Overview & Data Quality
Task 2: User Engagement
Task 3: User Experience / Network Quality
Task 4: Customer Satisfaction
Plotly graphs
Values reproduced from the submitted Task 1–4 notebooks
Run in VS Code
Open the folder in VS Code, then in the Terminal run:

python -m pip install -r requirements.txt
python -m streamlit run app.py
If Streamlit asks for an email during first setup, leave it blank and press Enter.

The browser should open at:

http://localhost:8501

Important
The dashboard uses the notebook-derived analytical values directly. It does not invent new analytical values.
